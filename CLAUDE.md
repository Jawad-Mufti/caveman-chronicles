## Conventions
- Talking is the player's choice: near a talker a bubble shows ("E"); E or the TALK touch button starts it
  (`_talkers` in level2.gd: [node, reach x, reach y, bubble offset, start]). Talking again gives a short varied line.
- Dialogue: keep lines short. A choice is `{"choose": [[answer, [lines...]], ...]}` in the lines; his answer is said as a
  CAVEMAN line, then its lines follow. New talkers get a tag colour in `Dialogue.TAGS` and a `speaking` var (`_talk`
  sets it). Tests that call `_next()` on a choice pick the first answer.
- Drawing: override `_paint()`; base `_draw()` builds a Batch and submits one triangle array. Helpers
  `_ln _pl _cc _pg _rc _ac _st _stm`. Scenery uses `Batch.new()` ... `b.draw(self)`. Redraw only when
  `NightWoods.near_view(self)` / `LevelBase.near_view(self)`.
- Darkness (`night.gd`): light sources join group "light" and implement `light() -> Vector4(x, y, radius, warmth)`
  and `light_strength()` (0 = decorative). Things that shine through the dark join "glow" and implement
  `draw_glow(g)` in world coordinates. `g` is ONE Batch shared by the whole glow layer (one draw call), so use
  only `g.draw_circle/draw_line/draw_colored_polygon/draw_set_transform` (reset the transform when done). Max 12 lights on screen.
- Critters: layer 4, `take_hit(dmg, dir)`, contact damage automatic. Breakables are layer-4 Areas with `take_hit`.
- Platforms: `World.Slab` / `NightWoods.Crag` are solid; one-way = `cs.one_way_collision = true` (Branch, SkyRock, Shelf).
- After a fall he is set down at the last FIRM spot: a static body, not in group "unsafe_ground", with ground under both
  sides of him. Anything that can break, burn or fall must join "unsafe_ground" (CrumbleRock, FallenLog, CrackedRock,
  PalisadeGate, Web); moving platforms (mammoths, tar logs) never count.
- Treasure ids: each shell id is taken ONCE per save. Never insert into the old tables (SHELL_ROWS, SHELL_POINTS,
  CONCHES, AMBERS, BREAKABLES, POTS, TOTEMS): ids are by index. Moving coordinates is fine; new loot gets its own
  id prefix (caves "v%d", pots "q%d_%d", sacs "sac<x>", sky lanes "k%d", caches "sc%d", Steppe "m%d", Tar Pits "t%d", Thunder Canyon "n%d", hoards "h%d", stomp spots "g%d", mountain chests "ch%d" Ã¢ÂÂ "x0"/"x1" are the old monkey stashes, now hoards).

## Pitfalls
- Duplicate names break a whole class and cascade ("Could not resolve class ..."). Check inner-class names.
- GDScript can't infer types from dict/array lookups: `var x: float = arr[i]`.
- Avoid new two-way class references between common/ and level2/.
- This PC has NO python. In Git Bash, give sed/awk/heredocs Unix temp paths (`T=$(cygpath -u "$TEMP")`); awk -v with a Windows path mangles it. An apostrophe inside a heredoc can break the shell: write the file with the Write/Edit tool instead.
- Textured things must set `texture_filter = TEXTURE_FILTER_LINEAR_WITH_MIPMAPS` (the project default is NEAREST: blocky).
- New files loaded with `preload` (grab.gd, spirit_orbs.gd) need no class_name and no project reload.
- FallingRock: total warning = `delay` + ~0.5 s fall; trigger distance for a runner Ã¢ÂÂ 300 ÃÂ that.
- Jawad's PC: stale `.godot` cache Ã¢ÂÂ delete `.godot` and reopen.
